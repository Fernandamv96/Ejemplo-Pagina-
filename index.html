Características

Todo lo necesario, nada que sobre

Una base sólida con buenas prácticas para que te concentres en tu contenido.

⚡

Sin configuración

No necesitas Node, npm ni compiladores. Abre el archivo en el navegador o usa Live Server de VS Code y verás los cambios al instante.

$ git clone Ejemplo-Pagina-
$ code .
✓ Listo para editar
📱

Responsive

Grillas con CSS Grid y Flexbox que se adaptan a celular, tablet y escritorio.

♿

Accesible

HTML semántico, foco visible, etiquetas en formularios y respeto por la preferencia de reducir movimiento.

🎨

Fácil de personalizar

Cambia colores, tipografía y bordes desde variables CSS en un solo lugar.

🚀

Lista para publicar

Súbela a GitHub y despliégala gratis en Vercel o GitHub Pages sin cambios.

Estructura

Ordenada desde el primer archivo

Cada archivo tiene una responsabilidad clara, así el proyecto crece sin desordenarse.

  • HTML
    index.html

    Estructura semántica: header, secciones, formulario y footer.

  • CSS
    style.css

    Variables de tema, reset, componentes y breakpoints.

  • JS
    script.js

    Eventos, validación del formulario y animaciones.

Cómo usar

De cero a publicada en tres pasos

  1. 01

    Descarga o clona

    Clona el repositorio con GitHub Desktop o descarga el .zip.

  2. 02

    Personaliza

    Edita textos en index.html y colores en las variables de style.css.

  3. 03

    Publica

    Haz push a GitHub e importa el repositorio en Vercel. Cada cambio se publica solo.
